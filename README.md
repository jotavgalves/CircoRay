# Parque dos Horrores

Jogo interativo de Halloween, pronto para hospedagem estática no Cloudflare Pages.

## Cloudflare Pages
- Framework: None
- Build command: deixe vazio
- Build output directory: `/`
- O arquivo de entrada é `index.html`.

O jogo é responsivo para dispositivos móveis.

Os áudios opcionais podem ser colocados em `assets/audio/`.
